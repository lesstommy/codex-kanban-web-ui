# Support

Codex Kanban Web UI is an alpha-stage, local-first development tool. Community support is provided on a best-effort basis.

## Before asking for help

1. Read the setup and security notes in [README.md](README.md).
2. Run `npm run doctor` and keep the non-sensitive output.
3. Search existing GitHub issues for the same symptom.
4. Confirm the installed Node.js, MongoDB, and Codex CLI versions.

## Usage questions

Open a GitHub issue and select the appropriate issue form. Include the expected behavior, actual behavior, operating system, version or commit, and a minimal reproduction.

Do not include access tokens, passwords, private prompts, local repository contents, full local paths, or unredacted logs.

## Bugs

Use the bug report form. Reproducible reports with focused logs and exact version information are the most useful.

## Feature requests

Use the feature request form. Explain the workflow problem first, then describe the proposed behavior and alternatives.

## Security vulnerabilities

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

## Commercial support

No commercial support or service-level agreement is currently offered.
